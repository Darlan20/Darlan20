### Desenvolvedor Full Stack focado em construir soluções de ponta a ponta.

</div>

Sou **Darlan Pereira**, desenvolvedor Full Stack apaixonado por tecnologia, desenvolvimento de sistemas e resolução de problemas.

Tenho experiência e estudos voltados para o desenvolvimento de aplicações utilizando **Java, Spring Boot, React, JavaScript, Node.js, Python e bancos de dados relacionais**.

Meu foco está em compreender o problema antes de escrever o código, buscando desenvolver soluções que sejam:

