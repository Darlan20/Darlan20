# 🚀 Projetos em destaque

## 🔧 SupportFlow

<div align="center">

### Sistema de gerenciamento de suporte técnico

</div>

O **SupportFlow** é uma aplicação Full Stack desenvolvida para gerenciamento de suporte técnico, permitindo organizar informações, usuários e processos relacionados ao atendimento.

O projeto foi estruturado separando **frontend e backend**, utilizando comunicação através de **APIs REST**.

### 🏗️ Arquitetura

```text
                 SUPPORTFLOW
                      │
        ┌─────────────┴─────────────┐
        │                           │
        ▼                           ▼
   FRONTEND                     BACKEND
   React/Vite                 Spring Boot
        │                           │
        │       REST API            │
        └─────────────┬─────────────┘
                      │
                      ▼
                 PostgreSQL
```

### 💻 Tecnologias

| Camada    | Tecnologia  |
| :-------- | :---------- |
| Frontend  | React       |
| Build     | Vite        |
| Backend   | Java        |
| Framework | Spring Boot |
| API       | REST        |
| Database  | PostgreSQL  |
| Deploy    | Render      |

### ✨ Funcionalidades

```text
✔ Autenticação
✔ Gerenciamento de usuários
✔ Perfil de usuário
✔ Alteração de senha
✔ Recuperação de acesso
✔ Gerenciamento de suporte
✔ Exportação de dados
✔ Integração Frontend + Backend
✔ API REST
```
